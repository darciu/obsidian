(Simple Storage Service)

s3 to jest obecnie tak naprawdę zestaw API's gdzie pierwszą implementacją jest AWS S3, Ceph implementuje te api i można korzystać z cepha w takim sam sposób w jaki AWS S3 lub Google Object Storage lub Azure Blob Storage

Za API s3 jest open source'owy CEPH.


Połączenie za pomocą boto w wersji 2
```
conn = boto.connect_s3(
aws_access_key_id='',
aws_secret_access_key='',
host='sds.dc-2.lb.dcwp.pl',
port=80,
is_secure=False,
calling_format=boto.s3.connection.OrdinaryCallingFormat()
)
```


tworzenie nowego bucketu
```
conn.create_bucket()
```

łączenie się z istniejącym bucketem
```
conn.get_bucket()
```

zbieranie wszystkich kluczy w buckecie (powyżej 1000 działa paginacja)
```
for key in bucket.list():
    keys.append(key)
```

ładowanie pliku (klucza) na bucket (publiczny lub z autentykacją)
```
key = bucket.new_key(name)
key.set_contents_from_filename('data/'+name)
key.set_acl('public-read')
# key.set_canned_acl('authenticated-read')
```

pobieranie pliku
```
key.get_contents_as_string()
```


URL do pobierania pliku z S3
```
{bucket}.{ceph host}:80/{nazwa klucza}
```
przykładowo
