2. ANSI/ISO SQL + model relacyjny (teoria)
3. PostgreSQL (pełnokrwisty RDBMS, open-source, najbogatsze możliwości)
4. MySQL lub MariaDB (naj­popularniejszy stos LAMP)
5. Microsoft SQL Server / T-SQL (duże firmy, BI, Windows stack)
6. MongoDB (NoSQL – dokumenty)
7. Redis (NoSQL – key-value, in-memory)
8. Cassandra lub DynamoDB (NoSQL – wide/column)
9. Neo4j (graf) lub orientacyjnie property-graph + Cypher
10. InfluxDB lub TimescaleDB (time-series)
11. Spark SQL / Databricks SQL lub Presto/Trino (Big Data / lakehouse)
12. Snowflake lub BigQuery (chmurowa hurtownia danych)

11 produktów to dużo, ale każdy reprezentuje bardzo popularny segment rynku. Poznanie jednego przedstawiciela z danej rodziny zwykle wystarcza, by „przełączyć się” później na konkurencyjny silnik.
